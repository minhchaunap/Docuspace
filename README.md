# 📁 DocuSpace Pro - Hệ Thống Lưu Trữ & Ghi Chú Đa Năng

Ứng dụng web quản lý tài liệu, ghi chú và bộ công cụ văn phòng tương tác (Word, Excel, PowerPoint, Note) tích hợp chia sẻ đa kênh (Zalo, Gmail, Google Drive).

## 🚀 Tính Năng Chính
- **Quản lý tệp & thư mục:** Tạo folder, đổi tên, sao chép (copy), di chuyển, xoá vào thùng rác và khôi phục.
- **Biên tập văn phòng:**
  - 📄 **Word (.docx):** Soạn thảo văn bản WYSIWYG, định dạng phong phú, chèn bảng, đếm số từ.
  - 📊 **Excel (.xlsx):** Bảng tính tương tác, hỗ trợ thanh công thức `fx`, tự động tính tổng (SUM), trung bình (AVERAGE), xuất CSV chuẩn UTF-8 chống lỗi font tiếng Việt.
  - 📽️ **PowerPoint (.pptx):** Thiết kế slide, đổi chủ đề, trình chiếu toàn màn hình (Fullscreen Slideshow).
  - 📝 **Ghi chú Note:** Ghi chú công việc theo thẻ tag kèm Checklist To-Do hoàn thành việc.
- **Chia sẻ đa kênh:** Tạo tin nhắn chuẩn và QR cho Zalo, tạo thư mẫu cho Gmail, đồng bộ Google Drive, Web Share API cho Facebook/Telegram/AirDrop.
- **Tải xuống an toàn:** Hỗ trợ tải trực tiếp và dự phòng đa phương thức, tự động lưu dữ liệu qua LocalStorage.

## 🌐 Hướng Dẫn Kích Hoạt GitHub Pages (Miễn phí)
1. Đăng nhập [GitHub](https://github.com) và bấm nút **New** để tạo Repository mới (đặt ở chế độ **Public**).
2. Tải toàn bộ nội dung trong thư mục này (gồm `index.html` và `README.md`) lên repository.
3. Vào tab **Settings** của repository -> Chọn mục **Pages** ở menu bên trái.
4. Tại phần **Branch**, chọn nhánh `main` (hoặc `master`) và thư mục `/(root)` -> Nhấn **Save**.
5. Sau 1 phút, GitHub sẽ cấp cho bạn đường link website trực tuyến dạng:
   `https://<ten-tai-khoan>.github.io/<ten-repo>/`
